01

Beyond ONE

A news intelligence system that ingests articles, generates alerts and validates them, with every alert traceable to its source.

  • Designed a Google Cloud Pub/Sub ingestion path for providers that poll on different schedules, feeding a downstream enrichment service.
  • Evaluated Graphiti and LLM versus non-LLM knowledge graph construction, with bitemporal modeling so past alert decisions stay reproducible as facts change.
  • Migrated the data model to a normalized chain: recommendations, alerts, item enrichment, source items.
  • Built a structured logging module on Loguru with scoped context and a fixed field order.

02

VISTOS

A surveillance platform that runs detection on a Jetson Nano and lets operators ask questions about what the cameras saw.

  • YOLO detection through DeepStream pipelines on the edge device.
  • A conversational agent that answers questions over surveillance history, with a context compaction prompt for long sessions.
  • Docker Compose deployment, a named Cloudflare Tunnel for stable public access, and a frontend hosted on GCP Compute Engine.
Jetson NanoYOLODeepStreamDocker ComposeCloudflare Tunnel
03

Blog Writing Agent

An LLM agent that researches a topic and drafts a blog post from what it finds.

  • FastAPI WebSockets connect the client to the agent pipeline.
  • OpenAI SDK with GPT-4o for drafting, and the Olostep API for research.
  • Ran architectural audits and prompt-layer reviews to tighten the pipeline.
FastAPIWebSocketsOpenAI SDKGPT-4o

Workflow Automation Platform

An agentic platform where users connect their own tools at runtime and let an agent orchestrate tasks across them.
