Opens every section: numbered `eyebrow` in amber, a display title, and an optional aside on the right.

The consumer provides the number (it must be the real order of sections), the title and one sentence of aside copy. Titles use `section-title` and may break across two lines with a `<br>`. The aside is `caption` size in `mute`, max 340px.

- Do: write the title as a plain statement, sentence case.
- Don't: add a subtitle, a button or an icon to the head.
