Pill button for contact actions. One `primary` per view (the email action); the rest are secondary.

Secondary buttons outline with `ctl` (at least 3:1), never `line`. Hover lifts 2px and turns the border `amber`. Focus is a solid 2px `amber` outline with a 4px offset. Labels use `button` and are uppercase.

The consumer provides the label and the href. Do not use a button to scroll between sections; that is the nav's job.
